# Radha Music project workflow

- Preserve the existing Android application ID and signing configuration so updates can replace existing installs.
- The user asked for completed project updates to be committed with descriptive messages and pushed to their GitHub repository. Keep the README current with features and build instructions. Do not force-push or overwrite unrelated remote work.
- Do not commit signing keys, credentials, local SDK paths, generated build outputs, or machine caches.
- The user tests on their own Android phone. Do not set up or run an emulator unless asked.
- Keep the visible credit: “Created, designed and developed by Diwash Bhatta”.
- Background playback must remain opt-in; preserve the original local media files.
